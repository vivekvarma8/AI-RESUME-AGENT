# 💼 AI Resume & Job Agent

An intelligent career assistant that analyzes resumes against job descriptions using AI.

## 🎯 Features

- **Resume Analysis**: Upload PDF/DOCX or paste text
- **Skill Matching**: AI-powered skill gap identification
- **Career Recommendations**: Personalized learning roadmap
- **RAG System**: Context-aware advice from career knowledge base
- **Beautiful UI**: Modern, responsive web interface

## 🛠️ Technologies

| Component | Technology |
|-----------|-----------|
| LLM | Google Gemini AI |
| Agent Framework | LangGraph |
| RAG/Embeddings | ChromaDB + Sentence Transformers |
| Backend | Flask |
| Frontend | HTML/CSS/JavaScript |
